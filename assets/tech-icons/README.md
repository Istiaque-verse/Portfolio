# Technology logo assets

The SVG marks in this folder were sourced from the [Simple Icons project](https://github.com/simple-icons/simple-icons), which distributes its icon files under CC0-1.0. The portfolio stores local copies so the logos work when the site is opened offline.

Simple Icons describes these as brand icons and asks users to read its [legal disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md). Company names and marks remain the property of their respective owners; their use here does not imply endorsement.

AWS uses a small typographic “aws” mark with the familiar smile stroke in the orbit. The machine-learning mark was replaced with FastAPI, which appears in the project technology list.
